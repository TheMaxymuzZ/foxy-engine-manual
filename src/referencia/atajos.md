# Atajos de teclado

En Mac se usa <kbd>Cmd</kbd>; en Windows y Linux, <kbd>Ctrl</kbd>.

## En todo el editor

| Atajo | Qué hace |
|---|---|
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>S</kbd> | Guardar lo que tienes delante |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>Z</kbd> | Deshacer |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>Mayús</kbd>+<kbd>Z</kbd> | Rehacer |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>,</kbd> | Preferencias (y cambiar las teclas) |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>K</kbd> | [Paleta de comandos](../editor/espacio-de-trabajo.md#la-paleta-de-comandos): buscar una acción, un panel o algo del proyecto |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>Mayús</kbd>+<kbd>M</kbd> | Maximizar el panel que tiene el teclado (y devolverlo) |
| <kbd>F5</kbd> | Jugar aquí / volver al editor |

Las teclas de moverse, de las herramientas y de jugar se pueden cambiar en
[Preferencias → Teclas](../guia/preferencias.md#teclas). Las de esta página
son las del esquema **Foxy**, el que viene. Con los esquemas **Como
Blender** y **Como Unity** cambian las del mundo: ver
[Si vienes de Blender o de Unity](../guia/blender-unity.md).

**Ayuda → <i class="fx fx-teclado"></i> Teclas y ratón…** enseña dentro del
editor las teclas principales.

## Mundo: herramientas

| Tecla | Herramienta |
|---|---|
| <kbd>C</kbd> | Cursor |
| <kbd>V</kbd> | Elegir y mover |
| <kbd>B</kbd> | Poner bloques |
| <kbd>E</kbd> | Quitar bloques |
| <kbd>P</kbd> | Pintar |
| <kbd>X</kbd> | Extruir |
| <kbd>N</kbd> | Pintar el suelo |
| <kbd>M</kbd> | Suavizar |
| <kbd>O</kbd> | Colocar objetos |
| <kbd>[</kbd> / <kbd>]</kbd> | Pincel más pequeño / más grande |

## Mundo: objetos

| Tecla | Qué hace |
|---|---|
| <kbd>R</kbd> | Girar el objeto elegido o el que vas a colocar (90° con imán, 15° sin él) |
| <kbd>G</kbd> | Encender o apagar el [imán a la rejilla](../guia/objetos-libres.md#el-imán-a-la-rejilla) |
| <kbd>F</kbd> | Llevar la cámara al objeto elegido |
| <kbd>Supr</kbd> o <kbd>Retroceso</kbd> | Borrar el objeto elegido |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicar el objeto elegido |
| <kbd>Esc</kbd> | Dejar de elegirlo |

## Mundo: manipuladores

| Tecla | Foxy | Como Blender | Como Unity |
|---|---|---|---|
| Mover (flechas) | <kbd>1</kbd> | <kbd>G</kbd> | <kbd>W</kbd> |
| Girar (anillos) | <kbd>2</kbd> | <kbd>R</kbd> | <kbd>E</kbd> |
| Escalar (cubitos) | <kbd>3</kbd> | <kbd>S</kbd> | <kbd>R</kbd> |
| Ejes del objeto o del mundo | <kbd>L</kbd> | Eje dos veces (<kbd>G</kbd> <kbd>X</kbd> <kbd>X</kbd>) | <kbd>X</kbd> |
| Herramienta Mano (desplazar la vista) | <kbd>H</kbd> | (no) | <kbd>Q</kbd> |
| Vista de frente / de lado / desde arriba | (no) | <kbd>1</kbd> / <kbd>3</kbd> / <kbd>7</kbd> | (no) |
| Perspectiva u ortográfica | (no) | <kbd>5</kbd> | (no) |

Mientras arrastras un manipulador, <kbd>Ctrl</kbd> invierte el imán.

## Mundo: cámara

| Tecla | Qué hace |
|---|---|
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Volar |
| <kbd>Espacio</kbd> / <kbd>Mayús</kbd> | Subir / bajar |
| Botón derecho + arrastrar | Mirar alrededor |
| <kbd>Alt</kbd> + clic y arrastrar | Mirar alrededor |
| Mantener <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> y mover el ratón | Mirar alrededor |
| Flechas | Girar sin ratón |
| Rueda | Acercarse o alejarse |

## Nodos

| Tecla | Qué hace |
|---|---|
| Clic derecho, <kbd>Espacio</kbd> o <kbd>Tab</kbd> | Buscar y añadir un nodo |
| <kbd>Mayús</kbd>+clic | Añadir a la selección |
| <kbd>Espacio</kbd>+arrastrar, botón central | Mover el lienzo |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+rueda o pellizcar | Acercar y alejar |
| <kbd>F</kbd> o <kbd>Inicio</kbd> | Ver todo el grafo |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>X</kbd>, <kbd>V</kbd> | Copiar, cortar y pegar nodos |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicar |
| <kbd>Supr</kbd> o <kbd>Retroceso</kbd> | Borrar lo elegido |
| <kbd>F9</kbd> | Poner o quitar un punto de parada |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>S</kbd> | Guardar el grafo |

| <kbd>Supr</kbd> | Borrar el elemento |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicar el elemento |

## Jugando

| Teclado y ratón | Mando | Qué hace |
|---|---|---|
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> o flechas | Stick izquierdo | Andar |
| Ratón | Stick derecho | Mirar |
| <kbd>Mayús</kbd> | Stick a fondo, L3 o gatillo izquierdo | Correr |
| <kbd>Espacio</kbd> | <span class="mando">A / <i class="fx fx-ps-cruz" title="Cruz"></i></span> | Saltar, nadar hacia arriba |
| <kbd>C</kbd> o <kbd>Ctrl</kbd> | <span class="mando">B / <i class="fx fx-ps-circulo" title="Círculo"></i></span> o R3 | Agacharse |
| <kbd>E</kbd> o clic | <span class="mando">X / <i class="fx fx-ps-cuadrado" title="Cuadrado"></i></span> o gatillo derecho | Usar un objeto, hablar, patear |
| La tecla de una pantalla (<kbd>I</kbd>, <kbd>M</kbd>, <kbd>Tab</kbd>…) | | Abrirla y cerrarla |
| <kbd>Esc</kbd> | Start | Pausa, cerrar una interfaz |
| <kbd>F5</kbd> | | Volver al editor (con *Jugar aquí*) |
| <kbd>F8</kbd> | | Enseñar u ocultar el grafo abierto en el panel Nodos, con sus cables encendidos |
| <kbd>F6</kbd> | | Seguir después de un punto de parada |
| <kbd>F7</kbd> | | Abrir y cerrar la ventana **Código** (guiones, consola y depurador) |
| <kbd>F10</kbd> | | Parado en un guion: la siguiente línea de la función |
| <kbd>F11</kbd> | | Parado en un guion: la siguiente línea, entrando en las funciones |
| <kbd>Mayús</kbd>+<kbd>F11</kbd> | | Parado en un guion: salir de la función |

## Panel Código

| Tecla | Qué hace |
|---|---|
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>S</kbd> | Guardar el guion (jugando, se recarga en el juego) |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>F</kbd> | Buscar y reemplazar |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>\\</kbd> | Dividir la vista en dos |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>/</kbd> | Comentar o descomentar las líneas elegidas |
| <kbd>Tab</kbd>, <kbd>Mayús</kbd>+<kbd>Tab</kbd> | Sangrar o quitar la sangría |
| <kbd>↑</kbd> <kbd>↓</kbd> y <kbd>Intro</kbd> o <kbd>Tab</kbd> | Elegir en el autocompletado |
| <kbd>Esc</kbd> | Cerrar el autocompletado |
| <kbd>F12</kbd> o <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+clic | Ir a la definición |
| Clic junto al número de línea | Poner o quitar un punto de parada |
